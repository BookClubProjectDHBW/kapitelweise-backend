# Kapitelweise – Buchclub-Backend (REST)

Dieser Service steckt hinter der Buchclub-Seite.

- Bücher per ISBN vorschlagen. Der Vorschlag ist sofort gespeichert und wird im Hintergrund geprüft. Danach sind Titel, Autor und Seitenzahl ergänzt.
- Alle Vorschläge eines Clubs ansehen.
- Admins wählen aus den Vorschlägen das aktuelle Buch und schließen es ab, wenn alle fertig sind.
- Admins planen Treffen, Mitglieder sagen zu oder ab und sehen, wer kommt.
- Alexa: Über einen eigenen Alexa-Skill kann man per Sprache fragen, in welchen Buchclubs man ist, welches Buch gerade gelesen wird und welche Vorschläge es gibt.
